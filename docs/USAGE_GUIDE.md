### 1.1 本地快速启动

```bash
# 启动 Studio 工作台
pnpm dev:studio
```
启动成功后，浏览器访问：👉 **`http://localhost:5174`**

## 2. 资产导入与工程管理 (Step 1)

### 2.1 本地图片与 EXIF 分辨率自动解析
- 点击 TopBar 上的 **“导入底图”** 按钮（或按快捷键）；
- 拖拽本地的高清架构图（PNG / JPG / WebP）至上传区域；
- 内置的 `imageDecoder` 引擎会在纯前端内存中毫秒级解析其真实物理像素（支持 4K/5K/8K 超高清大图），自动校正 EXIF 旋转角，并初始化视口边界。

### 2.2 模板中心：6 大预设架构一键克隆
如果你还没有现成的架构图，可点击 TopBar 的 **“模板中心”**，从 6 套内置的工业级经典模板中一键克隆体验：
1. **LuxeHMS 酒店 PMS 房态与高并发预订架构（经典升级版）**：包含网关、房态引擎、库存防超卖与支付链路；
2. **微服务高可用电商中台拓扑**：网关路由、订单中心与分布式缓存；
3. **FinTech 金融交易风控系统**：实时风控决策流与清结算架构；
4. **CloudNative 多云容灾架构**：多活流量调度与跨地域同步；
5. **AI 大模型知识库 RAG 流水线**：向量检索、重排序与大模型生成链；
6. **IoT 工业物联网高并发接入网关**：MQTT 协议解析与时序数据库存储。

### 2.3 本地工程管理器与 IndexedDB 500ms 防抖自动存盘
- **0 后端依赖**：全部工程数据均持久化在浏览器底层的 **IndexedDB** 数据库中；
- **防抖保存**：当你在工作台中修改任何参数、拖拽图元或增删场景后，系统会自动触发 **500ms 防抖静默存盘**；
- **工程管理**：点击 TopBar **“我的项目”**，即可呼出工程管理器，支持在多个架构演进工程之间瞬间切换、实时关键字模糊搜索、创建工程副本以及一键删除历史项目。

## 3. 可视化取景与 4 大标定工具链 (Step 2)

### 3.1 InfiniteCanvas 无限缩放与鼠标中心导航
- **无级缩放**：滚动鼠标滚轮，视口将**以当前鼠标光标所在的图元物理坐标为基准中心**进行几何缩放（0.1x ~ 5.0x），绝不漂移；
- **无限平移**：激活左侧 **“选择/抓手”** 工具，或按住鼠标中键/空格拖拽，即可平滑漫游整张宏大架构图。

### 3.2 镜头安全取景框与一键视口捕获
- 开启运镜模式时，画布上会以明亮的霓虹虚线框呈现 **`CameraFrustumFrame` 镜头安全取景框**，框内即为受众在大屏或演播时所见到的 100% 真实画面；
- 当你在画布上漫游并缩放到最完美的构图视角后，只需在右侧属性面板点击 **“📸 捕获当前画布视角”**，系统会自动逆向解算当前画布几何矩阵，精准回填至当前场景的 `camera` 参数中（含 `zoom`、`x%`、`y%`）。

---

### 3.3 矩形高亮选框与 Sobel 空间边缘智能吸附
- **手动拉框**：选择左侧 **“矩形选框”** 工具，在目标卡片（如微服务网关、Redis 缓存节点）上直接按下鼠标拖拽拉出选框；
- **Sobel 3x3 空间卷积吸附**：松开鼠标时，内置的 Sobel 边缘分析器会自动对选框周围 $\pm 24\text{px}$ 窄带区域计算空间灰度梯度，**自动精准咬合至卡片的物理几何边界**；
- **纯手动绕过**：若目标卡片没有明显边框，可按住 <kbd>Alt / Option</kbd> 拖拽，即可保留 100% 原始手动拉框尺寸。

---

### 3.4 8 向锚点捕捉与平滑三次贝塞尔流光连线
- **8 向智能磁吸**：选择左侧 **“贝塞尔连线”** 工具，鼠标靠近任意矩形卡片时，会自动高亮显示 **8 个法线锚点**（上中、下中、左中、右中、左上、左下、右上、右下）；
- **拖拽连线**：从起始卡片的锚点拖拽引线至目标卡片的锚点，松手即刻生成一条平滑优美的 **Cubic Bezier 三次贝塞尔曲线**；
- **霓虹流光脉冲**：连线默认搭载硬件加速的 SVG 描边动画与发光滤镜，完美表现数据流向与调用时序。

---

### 3.5 接口脉冲圆点与阶梯毛玻璃解说气泡
- **脉冲定位圆点 (Dots)**：选择 **“脉冲圆点”** 工具，在 API 接口、Kafka Topic 或特定网络端点上单击，即可放置一个呼吸发光的定位光斑；
- **毛玻璃解说气泡 (Callouts)**：选择 **“解说气泡”** 工具，在卡片旁点击即可挂载带有专业徽章标题与说明正文的毛玻璃卡片，支持配置多种主题色彩（Cyan / Violet / Emerald / Amber / Rose）。

---

### 3.6 右侧属性检查器 (RightInspector) 实时联动
- **运镜动力学**：精准微调放大倍率（Zoom）、运镜过渡时长（Duration，默认 1.2s）与缓动曲线；
- **图层可见性开关**：展开“当前场景图元”列表，支持对当前场景内的每一个选框、连线、圆点和气泡进行一键显隐勾选；
- **图元删除**：在检查器中点击垃圾桶图标即可一键清除无效图元。

## 4. 多场景编排、图层矩阵与时间旅行 (Step 3)

### 4.1 底部时间轴场景卡片流与原生 HTML5 拖拽重排
- 底部时间轴直观排列了演示过程中的每一个关键帧场景（如：`01 核心网关接入` $\rightarrow$ `02 订单秒杀链路` $\rightarrow$ `03 异步消息削峰`）；
- **拖拽重排**：按住任意场景卡片，可直接左右拖动调整演播顺序；
- **动态总时长**：时间轴右上角会实时累加各场景过渡与驻留时长，精准预估整场演示时间。

### 4.2 场景双击内联重命名与复制/删除操作
- **内联改名**：双击任意场景卡片上的标题文字，即可激活内联输入框修改标题，修改后与右侧检查器实时双向同步；
- **浮动操作键**：鼠标悬停在卡片上，会浮现 **“复制副本”**（一键克隆当前场景全部运镜与图元）和 **“删除场景”** 按键。

### 4.3 图层可见性矩阵与跨场景一键图元继承
在复杂架构演进中，后续场景往往需要继承上一幕已经激活的高亮图元：
- 切换至第 N 幕时，在右侧检查器点击 **“⚡ 继承上一幕全部图元”**，系统会自动将上一幕的激活图元深拷贝至当前场景，大幅减少重复配置时间。

### 4.4 50 步不可变撤销与重做 (⌘Z / ⌘⇧Z 时间旅行)
- 工作台内置了高性能、不可变的 **50 步历史快照栈**；
- 无论执行了增删图元、修改运镜、拖拽重排时间轴还是重命名，随时可使用 TopBar 上的撤销/重做按钮或快捷键：
  - <kbd>⌘Z</kbd> / <kbd>Ctrl+Z</kbd>：撤销上一步操作；
  - <kbd>⌘⇧Z</kbd> / <kbd>Ctrl+Y</kbd>：重做恢复变更。

### 5.1 纯前端单文件独立 HTML 编译器 (0 依赖双击秒开)
- 点击 **“立即下载 .html 文件”**；
- `standalonePackager` 引擎会在浏览器内存中将当前工程 DSL、Base64 图片、播放引擎 IIFE 与样式表融合成单个 `.html` 文件；
- **优势**：接收者无需安装任何环境或打开本地服务，双击即可在任意电脑（Mac / Windows / Linux）的浏览器中全屏满帧体验 60FPS 运镜！

### 5.2 标准工程 ZIP 归档包打包与分发
- 切换至 **“工程 ZIP 归档包”** Tab，点击 **“立即下载 .zip 压缩包”**；
- `zipExporter` 基于 `jszip` 在纯前端生成包含 `config.json`（标准 DSL）、`assets/`（原始高清素材）、`index.html` 与 `README.md` 的标准 ZIP 压缩包，方便二次开发与版本归档。

### 5.3 纯前端 60FPS WebM 高清视频无损录制
- 切换至 **“客户端视频录制”** Tab，点击 **“启动全自动录制”**；
- `canvasRecorder` 将调用 HTML5 `MediaRecorder` API 与硬件加速 VP9 编码器，对画布连贯运镜与流光动效进行纯本地 60FPS 实时录制，直接导出高清 WebM 视频文件。

### 5.4 100vw × 100vh 讲台受众全屏演播模式
- 点击 TopBar 上的 **“演播”** 按钮（或按快捷键）；
- 工作台将切换至真实的受众演播视角（100vw × 100vh 沉浸式挂载，隐藏所有编辑器边框与工具栏）；
- **讲台控制**：
  - 按 <kbd>→</kbd> / <kbd>Space</kbd>：流畅过渡至下一场景；
  - 按 <kbd>←</kbd>：回退至上一场景；
  - 按 <kbd>F</kbd>：进入/退出浏览器原生全屏；
  - 按 <kbd>ESC</kbd>：退出演播模式返回编辑工作台。

### 6.2 常见问题解答 (FAQ)

#### Q1: 导出的单文件 HTML 在离线断网环境下可以使用吗？
> **A**: 100% 可以。导出的 `.html` 文件中内联了 Base64 图片数据、SVG 矢量滤镜、CSS 样式表以及编译好的播放器 IIFE 引擎代码，没有任何外部 CDN 链接或网络请求，完全自主可控。

#### Q2: 为什么导入大图后，偶尔在控制台看到 CORS 警告？
> **A**: 这是浏览器 Canvas 的同源安全机制（Tainted Canvas）。当使用远程未配置 CORS 的 URL 导入图片时，Sobel 像素级吸附会安全降级为纯手动选框模式，并不影响正常的选框绘制与运镜保存。导入本地文件或 Data URI 图片时则拥有完整的 Sobel 智能边缘吸附能力。

#### Q3: 如何在其他 Web 系统中嵌入 FocusFlow 导出的演播效果？
> **A**: 两种方式：
> 1. 通过 `<iframe>` 直接嵌入导出的 `index.html`；
> 2. 在前端项目中引入 `@focusflow/player`，通过 `new FocusFlowPlayer({ container, dsl })` 实例化驱动。

## 附录：FocusFlow 核心动效体系与物理模型说明

FocusFlow 播放引擎内置 6 大工业级物理动效体系，所有动效均在 60FPS 硬件加速轨道上运行：

1. **Cinema Camera Kinematics（电影级运镜动力学）**：
   采用标准三次贝塞尔缓动 `cubic-bezier(0.4, 0.0, 0.2, 1.0)` 进行 Scale & Pan 视口映射与重心平滑推移。
2. **Neon Glow Pulse（霓虹辉光与边缘呼吸）**：
   SVG 高斯模糊滤镜 (`#ff-glow`) + 动态 `drop-shadow` 呈现高端科技感边缘辉光。
3. **Stream Data Flow（三次贝塞尔流光数据流）**：
   利用 8 向法线向量推导控制点，结合 `stroke-dasharray` 与 `stroke-dashoffset` 实现连贯的高速流光动画。
4. **Endpoint Pulse Rings（端点脉冲光环）**：
   双层同心圆结构，外环进行 1.8s 无限循环的扩散涟漪，强化接口交互存在感。
5. **Staggered Frosted Glass Callouts（阶梯弹入毛玻璃气泡）**：
   CSS `backdrop-filter: blur(12px)` 结合 0.15s 阶梯出场延时与回弹曲线，呈现层次分明的文字解读。
6. **PiP Inset Drill-down（画中画实景下钻动画）**：
   支持在宏观拓扑图上方以 `zoom-fade` 动效弹入局部微观实景截图，展示深层次代码或链路详情。
