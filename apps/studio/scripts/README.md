# FocusFlow CPU 占用率与资源泄漏实测采样工具

`measure-cpu.mjs` 是 FocusFlow 专门用于监控和验证浏览器端 CPU 负载、动效开销与系统级音视频硬件资源泄漏的本地采样工具。

---

## 1. 产生背景

在 FocusFlow Studio 的日常运行与视频录制过程中，可能会遇到以下 3 类系统级性能瓶颈：
1. **画布静态编辑态 CPU 偏高**：主画布 SVG 包含无限循环流光与 `filter: drop-shadow` 滤镜，导致浏览器光栅化线程（Raster Threads）每秒 60 次强制重绘；
2. **视频录制时多核满载**：Retina 高分屏（3K/4K）未设分辨率上限，VP9 编码器在 60FPS 下触发多线程纯 CPU 软件编码，拉满 300%~400% CPU；
3. **关键操作后资源泄漏**：混音 `AudioContext` 或 `MediaStream` 录制流未被显式 `close()`，即使停止演播，系统底层 CoreAudio / WASAPI 声卡线程仍持续在后台空转。

为实现科学的**“基线测量 ➔ 实施治理 ➔ 量化验证”**闭环，本脚本通过 macOS 原生 `ps` 采样体系，零依赖、高精度地实时监控浏览器渲染子进程（Renderer Process）的性能表现。

---

## 2. 快速开始 (Quick Start)

### 常用命令

在工程根目录下执行：

```bash
# 默认采样 5 秒
pnpm --filter @focusflow/studio test:cpu

# 自定义采样时长（如连续采样 10 秒）
node apps/studio/scripts/measure-cpu.mjs 10

# 视频录制或压力测试采样 30 秒
node apps/studio/scripts/measure-cpu.mjs 30

# 查看 CLI 内置帮助文档
node apps/studio/scripts/measure-cpu.mjs --help
```

## 3. 输出指标解析

脚本每秒采集并输出当前系统中最高负载渲染进程的实时快照，并在采样结束后输出统计报告：

```text
[09:23:17] 采样 #1/3 ➔ 负载最高 PID: 3900  | CPU: 110.1% | 内存: 30.2%
[09:23:18] 采样 #2/3 ➔ 负载最高 PID: 3900  | CPU: 101.6% | 内存: 30.2%
[09:23:19] 采样 #3/3 ➔ 负载最高 PID: 3900  | CPU: 118.4% | 内存: 28.5%

================== 📊 统计汇总分析 ==================
PID 3900:
  - 峰值 CPU: 118.4%
  - 最低 CPU: 101.6%
  - 平均 CPU: 110.0%
  🚨 严重告警: 该进程处于极高满载状态 (>90% CPU)，存在严重的动效重绘或音频线程泄漏！
```

- **PID**：操作系统级 Chrome/Chromium 渲染进程唯一编号；
- **CPU%**：该进程当前占用的 CPU 百分比（100% 代表 1 个 CPU 物理/逻辑核心完全跑满）；
- **内存%**：该进程占用的系统物理内存百分比；
- **健康评级**：
  - 🟢 **状态优良 (< 15% CPU)**：处于正常空闲或极低负载状态；
  - 🟡 **状态正常 (15% ~ 90% CPU)**：处于正常运镜播放或 1080P 60FPS 录制编码负荷；
  - 🚨 **严重告警 (> 90% CPU)**：存在死循环重绘、多核打满或未释放的音频/媒体流线程泄漏。

## 4. 三大核心测试场景与量化对照基准

| 测试场景 | 测试步骤 | 治理前现状 (实测基线) | 治理后预期目标 | 达标判定 |
| :--- | :--- | :--- | :--- | :--- |
| **场景一：Studio 静态编辑态** | 打开 Studio 编辑器，保持鼠标在画布中静止 10 秒，运行采样脚本。 | **106% ~ 118% (单核跑满)** | **< 5% ~ 8% (静止休眠)** | ✅ 通过 |
| **场景二：60FPS 视频录制中** | 从导出中心启动客户端 60FPS 录制，全屏演播播放中运行采样脚本。 | **300% ~ 400% (多核过载)** | **60% ~ 100% (平稳编码)** | ✅ 通过 |
| **场景三：录制结束 / 停止演播** | 录制完成或按 ESC 退出演播 3 秒后，运行采样脚本。 | **100%+ 居高不下 (硬件线程泄漏)** | **瞬间回落至 < 5% (硬释放)** | ✅ 通过 |
